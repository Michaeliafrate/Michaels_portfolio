NFL Full-Stack Application Project

This was a team project for MIST 353. Each of us built our own version of a full-stack NFL app. The app lets fans log in and follow their teams, and lets admins schedule games, with each scheduled game logged against the admin who made it.

The app has three parts: a SQL Server database on Azure with stored procedures and a trigger, a FastAPI back end that exposes those procedures as REST endpoints, and a Streamlit front end that calls the API. A GitHub Actions workflow deployed the API to Azure App Service on every push. I built the front end from more than ten reusable components, tested the API endpoints, and worked in weekly sprints. I used Claude to help with debugging and code review.
